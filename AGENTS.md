# Skybliss Rooftop Resto Lounge — Project Rules

This project is built with **React + Vite + TypeScript**, using Tailwind CSS v4, GSAP, Framer Motion, and Lenis.
- Entry point: `index.html` -> `src/main.tsx` -> `src/App.tsx`
- Development: `npm run dev` (Vite)
- Build: `npm run build` (outputs to `dist/`)
- Public assets: `public/` (served at `/`)
